# Personaje GLB

Coloca aquí el archivo exportado desde Blender:

`player.glb`

El juego detectará automáticamente este archivo al iniciarse y cargará sus animaciones:
- Idle
- Walk
- Run
- Jump
- Fall
- Land
- CastSpell
- Hit

Si el archivo aún no existe, el juego utilizará automáticamente el modelo procedimental de aprendiz de mago.
